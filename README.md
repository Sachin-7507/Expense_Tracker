# 💰 Expense Tracker (Full Stack Application)

A full-stack Expense Tracker web application built using React (Frontend) and Spring MVC / Spring Boot (Backend) with MySQL database. It helps users track daily expenses, manage financial records, and analyze spending habits.

---

## 🚀 Features

- User Registration & Login
- Secure Authentication
- Add, Update, Delete Expenses
- View Personal Expense History
- Category-wise Expense Tracking
- Date-wise Filtering
- Expense Summary Dashboard
- Responsive UI

---
